# 案件選定とCTA配置計画：home-cleanout-visit-buyers

## 選定した案件と最新性判定の根拠
1. **バイセル（BuySell）**
   - **方針**: 条件付き主力 / 優先度S
   - **用途**: 混在品（着物・切手・古銭など）の価値確認の主導線
   - **最新性判定**: `SKILL.md` および `program-baseline-2026-08-07.md`（確認日2026-07-29）に基づき提携済み。※掲載前にASP管理画面で現行条件の再確認が必要。
2. **ブラリバ（Brand Revalue）**
   - **方針**: 主力 / 優先度S
   - **用途**: ブランドバッグ、時計、宝石などが複数ある場合の専門査定導線
   - **最新性判定**: `SKILL.md`（ブランド特化の推奨ルート）。※掲載前にASPにて提携状態と成果地点の確認が必要。
3. **美術品買取専門店 獏（バク）**
   - **方針**: 主力 / 優先度S
   - **用途**: 掛け軸・茶道具・古美術の専門査定導線
   - **最新性判定**: `SKILL.md`（骨董品の推奨ルート）。※掲載前にASPにて提携・査定条件の確認が必要。
4. **ニーゴ・リユース**
   - **方針**: 条件付き主力 / 優先度A
   - **用途**: 楽器・オーディオ等趣味品の査定導線
   - **最新性判定**: `SKILL.md`（趣味品の推奨ルート）。※対象エリアの確認が必要。

※**ハッピープライス**および**福ちゃん**は最新の `revenue-pages.md` および `SKILL.md` の方針（保留）に従い、今回選定・配置しません。

## 挿入予定箇所とロジック（ブリッジ）

### 1. 着物・切手・古銭・ブランド品が混在する場合（H3）
- **対象案件**: バイセル
- **ブリッジ**: 混在している品目を一つひとつ自分で仕分けるのは大変です。まずは幅広い品目に対応している総合買取サービスへ、手元の品物が対象になるかまとめて相談してみましょう。
- **配置予定**: H3セクションの末尾

### 2. ブランド時計・宝石・ブランドバッグが中心で価格を比べたい場合（H3内の文脈）
- **対象案件**: ブラリバ
- **ブリッジ**: 価値の高いブランド品や時計が複数ある場合は、専門知識を持つ査定士にしっかり見てもらうのが安心です。
- **配置予定**: 上記1. のセクション内でブラリバに言及している段落の直後

### 3. 骨董品・茶道具・古美術が中心の場合（H3）
- **対象案件**: バク
- **ブリッジ**: 作者が分からない骨董品でも、専門の査定士が見ると思わぬ価値が判明することがあります。処分してしまう前に、写真などで一度相談してみましょう。
- **配置予定**: H3セクションの末尾

### 4. 楽器・オーディオなど大型の趣味品が中心の場合（H3）
- **対象案件**: ニーゴ・リユース
- **ブリッジ**: 重くて運び出せない大型の趣味品や、音が出るか分からない楽器でも対象になる場合があります。まずは現状を伝えて、出張対象になるか確認してみましょう。
- **配置予定**: H3セクションの末尾

## 補足：案件を置かない箇所
- **10秒判断ブロック**: ルールに従い、リンク（CTA）は配置しません。
- **不用品回収業者**: 本記事は「出張買取業者」の選び方に特化しているため、不用品回収の直接の案件（CTA）は置かず、既存の「あわせて読みたい（choose-waste-collector）」による内部リンク誘導に留めます。
