# Source Checks

Use this reference only when the audit touches Google guidance, law, regulation, public safety, disposal rules, consumer trouble, or claims that need current evidence.

## Google Official Sources

- Helpful, reliable, people-first content: https://developers.google.com/search/docs/fundamentals/creating-helpful-content
- Japanese version: https://developers.google.com/search/docs/fundamentals/creating-helpful-content?hl=ja
- Search Essentials: https://developers.google.com/search/docs/essentials
- Spam policies: https://developers.google.com/search/docs/essentials/spam-policies
- Title links in Search: https://developers.google.com/search/docs/appearance/title-link
- Search Quality Rater Guidelines overview and PDF links: https://www.google.com/search/howsearchworks/how-search-works/rigorous-testing/

Use these as self-assessment guidance, not as a promise of ranking or indexing.

## Verification Rules

- Browse when the claim involves current law, regulation, procedure, target items, penalties, fees, public warnings, or Google guidance.
- Treat local government rules as local, not national.
- Prefer current official pages over old PDFs, media articles, affiliate pages, or SEO blogs.
- Keep the article voice practical: cite or link the source where trust matters, then translate it into the reader's next action.
- If no current official source is found, mark the claim as `要確認` rather than filling the gap with memory.
